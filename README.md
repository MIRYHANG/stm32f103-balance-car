# STM32F103 平衡车学习项目

本项目用于学习和复刻江科大的 STM32 平衡车项目。

目前主要目的是通过实际编写代码，学习 STM32 外设驱动、MPU6050 姿态传感器、电机控制、编码器、PID 控制等内容，并逐步完成一个可以自主平衡的两轮平衡车。

> 项目目前处于学习和开发阶段，代码会随着学习进度持续更新。

---

## 1. 项目目标

计划完成一个基于 STM32F103 的两轮自平衡小车，主要包括：

- MPU6050 姿态传感器驱动
- 加速度计、陀螺仪数据读取
- 姿态角计算
- 电机 PWM 控制
- 编码器测速
- 直立环 PID
- 速度环 PID
- 转向控制
- 最终完成两轮自平衡控制

---

## 2. 硬件

目前使用：

- MCU：STM32F103C8T6
- 姿态传感器：MPU6050

其他硬件将在项目开发过程中逐步补充。

## 5. 当前 MPU6050 初始化流程

目前已经完成 MPU6050 的基础初始化，包括相关寄存器配置。

当前主要学习重点是：

1. 理解 MPU6050 寄存器作用
2. 理解 STM32 HAL I2C 通信过程
3. 根据 MPU6050 Register Map 编写驱动
4. 理解采样率、低通滤波器、陀螺仪和加速度计量程配置
